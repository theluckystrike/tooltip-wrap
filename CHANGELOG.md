# Changelog

## 1.0.0

First release, for Fabric on Minecraft 26.3. Client side only.

- A tooltip that would run off the screen is wrapped onto more lines so the whole box fits, next to the mouse when there is room, otherwise across the screen.
- Colors and text styles are kept. Pictures in tooltips (maps, bundles) are kept as they are.
- Tooltips that already fit are not changed.
- Config file `config/tooltip-wrap.json` with an on/off switch and the narrowest width to wrap to.
